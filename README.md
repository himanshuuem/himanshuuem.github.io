# himanshuuem.github.io

Personal site of Himanshu — M.Tech (IT), IIEST Shibpur. Live at **https://himanshuuem.github.io**.

A single static page: plain HTML and CSS, no framework, no JavaScript, no trackers.

- `index.html` — the whole site (styles inline)
- `img/` — portrait (WebP), favicon, social-share card
- `fonts/` — self-hosted Barlow, Barlow Condensed and JetBrains Mono (SIL Open Font License, see `fonts/LICENSE-*`)

To edit: change `index.html` and push to `master`; GitHub Pages redeploys in about a minute.
